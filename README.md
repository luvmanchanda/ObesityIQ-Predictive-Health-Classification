# ObesityIQ-Predictive-Health-Classification
• Prepared 20,000+ health records for obesity classification through data cleaning and categorical encoding
• Compared three classifiers using 3-fold stratified cross-validation and selected Random Forest by mean macro F1
• Used permutation importance on validation data to select four of sixteen features, reducing required inputs by 75%
• Achieved 88.03% test accuracy with four features, compared with 89.04% using all sixteen obesity predictors
